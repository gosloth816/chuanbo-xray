# 齐鲁卖点 · 创作与发布前审核

面向普通农产品的产品信息确认、多渠道文案创作与传播X光审核工具。界面按用户选择的Apple方向设计。

## 当前功能

- 上传JPG、PNG或WEBP图片与介绍；可选真实多模态模型识别。
- 人工确认产品名称、产地、规格、特点、价格等事实。
- 选择受众、渠道和语气，调用已配置模型创作商品详情页、朋友圈、短视频口播文案。
- 编辑文案并保存修改前后记录，导出Markdown和JSON。
- 一键将已保存文案与事实快照送入传播X光，逐条核对、人工复核并导出审核报告。
- 原传播X光完整功能保留于侧栏“传播X光审核”；独立入口为xray_app.py。

## 运行

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

也可以运行原有run.ps1或run.bat。演示入口“加载合成演示”不调用模型，所有图片和文案均明确标注合成。

## 配置真实模型

应用从环境变量读取配置，不自动读取.env文件。默认连接本机兼容服务；本机必须已启动支持图片的模型。

```powershell
$env:STUDIO_MODEL_BASE_URL = 'http://127.0.0.1:11434/v1'
$env:STUDIO_MODEL_NAME = '填写本机实际安装的视觉模型名称'
.\.venv\Scripts\python.exe -m streamlit run app.py
```

远程服务需设置STUDIO_MODEL_BASE_URL、STUDIO_MODEL_NAME、STUDIO_MODEL_API_KEY，地址须为HTTPS。请使用服务商当前官方文档中的兼容接口与可用模型名。远程调用前页面要求确认数据发送；调用可能产生费用，本项目不自动购买服务。不在报告、日志或代码中保存密钥。

2026年10月31日已在公开网站使用 qwen3.8-flash 完成真实图片识别、多渠道生成、JSON下载与传播X光交接测试，记录见 docs/cloud_real_model_check.json。输入为明确标记的合成商品与插画；该测试不代表真实商家使用效果。早期本机服务失败记录保留供追溯。应用未训练或微调模型。

## 验证与边界

54项自动测试通过，覆盖原审核流程、新创作流程、失败不回退、未知事实编号拒绝、事实变更后禁止旧稿送审以及创作到审核交接。浏览器实际检查覆盖合成演示、编辑留痕、JSON下载、传播X光交接和手机布局；另已完成一次云端真实模型全流程验证，使用合成测试商品。

图片不能证明甜度、产地认证、保质期或功效。商家确认信息不是独立证明；引用编号和简单规则也不能保证文案完整真实。所有输出是待审核草稿。识别结果须人工确认；修改事实后应重新创作，未保存编辑不会导出或送审。

## 不占用个人电脑的云端方式

沿用原Streamlit公开网站；远程视觉模型在服务商云端运行。配置结构见deploy/streamlit-secrets.example.toml，步骤见docs/DEPLOY_STREAMLIT_CLOUD.md。云端没有模型配置时会停用AI调用，不连接本机地址；未确认免费额度用完即停保护时也会阻止调用。服务商账户开通、额度状态及密钥需要账户本人在控制台配置。应用不注册账户、不充值、不购买服务。
