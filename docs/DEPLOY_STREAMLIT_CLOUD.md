# 齐鲁卖点云端更新

现有应用沿用GitHub仓库gosloth816/chuanbo-xray、master分支、app.py入口，公开地址仍为https://chuanbo-xray.streamlit.app。网页和模型均在云端运行，不需要作者电脑开机。

## 云端模型设置

在Streamlit应用管理页的Settings → Secrets配置服务器端变量，不能把密钥提交到GitHub或发送到聊天。示例结构见deploy/streamlit-secrets.example.toml。

可采用百炼北京地域的、账号中确实还有免费额度的视觉理解模型。平台当前新人免费额度通常有效90天，具体模型与剩余额度以账号控制台为准。必须先在服务商控制台开启对应模型的“免费额度用完即停”，确认生效后，才把STUDIO_FREE_QUOTA_CONFIRMED设置为true。这个应用开关只记录管理员确认，不能代替服务商的计费保护。额度不支持模型训练或自定义部署，项目不进行训练、充值或购买。

官方依据：https://help.aliyun.com/zh/model-studio/new-free-quota

应用默认阻止未配置密钥或未确认免费额度保护的云端调用，不会退回连接作者电脑的localhost，也不会切换付费模型。额度耗尽或到期时停止创作，合成演示和人工审核仍可用。接口报错不会回退为固定文案假装AI成功。
