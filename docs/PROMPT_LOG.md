## 大模型增强路径

### 1. 宣传主张提取

约束：

- 只提取宣传材料原文中的完整句子；
- 不补充原文没有的信息；
- 不生成新文案；
- 只返回 JSON；
- 对每条提取结果执行原文逐字定位，定位失败则终止分析。

### 2. 证据核对

输入只包含当前主张和检索到的候选原文。

约束：

- 不能使用外部知识；
- 不能编造来源、页码、数据和结论；
- `verdict` 只能是 `supported`、`conditionally_supported`、`insufficient`、`conflicting`、`manual_review`；
- 没有候选证据时必须是 `insufficient`；
- 引用必须逐字摘录候选原文；
- 模型引用随后由程序再次校验；
- 引用未通过校验时转为 `manual_review`。

## 离线规则路径

离线规则模式不调用大模型，其判断来自：

1. 中文字符二元组与数字 token 的 BM25 风格检索；
2. 数值和单位提取；
3. 指标上下文和数值差异检查；
4. 条件、试验范围与限制语提示；
5. 绝对化、全覆盖和否定性证据提示；
6. 候选证据原文逐字校验。

## 版本记录规范

后续修改提示词或规则时，应同步更新：

- `src/constants.py` 中的 `PROMPT_VERSION`；
- 本文件；
- 相关自动测试；
- 测试与评估结果；
- AI 使用说明。

不得删除旧版本后继续沿用同一版本号。若提示词或判断规则发生实质变化，应提升版本号并重新运行完整验证。
