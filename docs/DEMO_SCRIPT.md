# 演示脚本（约 3 分钟）

## 演示前准备

1. 在项目目录运行 `.\run.ps1`；
2. 浏览器打开终端显示的本地地址；
3. 确认页面显示“本地处理、无付费接口”；
4. 在“新建诊断”选择“绿盾一号合成演示案例”。

## 0:00-0:20 说明问题

“农业科技宣传里最难核查的不是句子写得漂不漂亮，而是这句话有没有资料支持、试验条件有没有被省略、数值有没有冲突。传播 X 光把宣传主张、原始证据和人工结论连成一条可复查的记录。”

强调：本产品不生成产品效果，不自动判定违法或造假。

## 0:20-0:45 创建任务

1. 展示宣传文案、产品资料、海报入口；
2. 说明默认本地处理，不需要付费模型或 API 密钥；
3. 点击“加载合成演示案例”；
4. 指出页面和材料均标注“合成测试数据”。

## 0:45-1:45 查看诊断结果

切换到“证据审查台”，依次讲解：

- “有资料支持”：资料中存在直接相关内容；
- “有条件支持”：82.4% 的防效来自特定地区、品种和试验条件，宣传没有说明边界；
- “资料冲突”：宣传写 92%，试验摘要为 82.4%；
- “证据不足”：农药减量 50%、所有番茄品种、无残留均没有相应资料支持。

打开其中一条证据，展示文件、段落、原文和“逐字校验通过”。

指出：没有找到证据不等于证明宣传虚假，只表示当前上传资料不足。

## 1:45-2:20 人工复核

选择一条风险主张：

1. 处理方式选择“修改判断”或“驳回主张”；
2. 填写复核人；
3. 填写人工意见，例如“资料未覆盖农药减量比例，需删除量化表述”；
4. 填写最终表述；
5. 保存并展示复核状态变化。

说明人工修改和理由会写入本地操作留痕。

## 2:20-2:45 导出报告

切换到“导出报告”：

1. 展示风险分类统计；
2. 展示仍有未复核主张的提醒；
3. 下载 HTML 或 JSON；
4. 展示报告中的原文证据、人工结论、使用边界和操作留痕。

## 2:45-3:00 验证与边界

切换到“关于与验证”：

- 展示 AI 使用披露；
- 展示实际测试记录和合成验证集结果；
- 强调验证集是合成数据，不能外推为真实业务准确率；
- 说明本地大模型路径尚未完成实际连接验证；
- 说明正式发布仍需企业审核、专业判断和法律审查。

## 演示注意

- 不要把合成案例描述成真实产品；
- 不要宣称“系统能自动判断违法或造假”；
- 不要宣称模型准确率或效率提升比例，除非有真实用户测试记录；
- 如本地大模型未连接，明确展示离线规则模式。
