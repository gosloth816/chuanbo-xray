# 赛道三要求对照

| 赛道三要求 | 当前实现 | 可检查证据 |
| --- | --- | --- |
| 聚焦具体营销传播痛点或决策环节 | 面向农业科技、植保产品宣传材料发布前审核 | `docs/PRODUCT.md` |
| 工具真实可运行、可交互 | Streamlit Web 应用，上传、诊断、复核、导出均可操作 | `app.py`、`src/ui_*.py`、自动界面测试 |
| 评审无需指导即可独立跑通 | 内置三个合成演示案例，可一键加载 | “新建诊断”页面、`README.md` |
| 明确目标用户和使用频率 | 企业市场宣传人员和审核人员；每次材料定稿前使用 | `docs/PRODUCT.md` |
| 衡量效率或质量改善 | 记录主张数、分类、引用校验、耗时；真实业务测试尚待开展 | `docs/TEST_PLAN.md`、`docs/evaluation_results.md` |
| 明确人机分工边界 | AI/规则输出建议，人工确认、修改、驳回；报告必须人工复核 | “证据审查台”、`docs/AI_USE_DISCLOSURE.md` |
| 结果校验机制 | 引用必须在原文逐字找到；失败转人工核验 | `src/evidence.py`、`src/pipeline.py` |
| 人工干预通道 | 每条主张可确认、修改、驳回并填写理由和最终表述 | `src/ui_review.py` |
| 输出可编辑、可导出、可溯源 | HTML、Markdown、JSON 导出，保留来源位置和操作留痕 | `src/report.py`、`src/storage.py` |
| 容错运行 | 文件格式错误、无文本、模型失败均明确提示 | `src/parsing.py`、`src/pipeline.py` |
| 提示词版本和人工修改记录 | 提示词版本、模式、模型、复核事件写入记录 | `src/constants.py`、`docs/PROMPT_LOG.md`、SQLite 审计表 |
| 产品说明与运行证据 | 产品说明、AI 披露、测试记录、演示脚本 | `docs/`、`docs/verification.json` |
| 数据来源和模拟数据标注 | 三个案例文件、界面和报告均标注合成测试数据 | `data/demo/*/case_meta.json`、界面提示 |
| 实际运行案例 | 三个合成案例已实际运行；真实企业案例尚待补充 | `docs/evaluation_results.json` |
| 不直接套用未加工 AI 成品 | 代码、测试、规则和文档均经过本地运行与人工审查；未声称真实用户反馈 | `docs/AI_USE_DISCLOSURE.md` |
| 不产生付费环节 | 不购买服务、不设置充值或订阅；公开部署使用平台免费额度 | `docs/DEPLOY_STREAMLIT_CLOUD.md`、界面隐私提示 |

## 尚需在正式提交前完成

1. 如有条件，邀请真实审核人员完成一轮小范围测试并保存原始记录；
2. 如使用真实企业材料，取得合法授权并注明来源；
3. 录制实际运行视频；
4. 按学校要求填写报名表、团队汇总表、诚信承诺书；
5. 按“赛道三-学校名称-团队名称-项目名称”命名最终压缩包；
6. 完成团队、指导教师和作品名称等信息核对。

以上事项在当前版本中尚未完成，不应在申报材料中表述为已完成。
