# 测试计划

## 一、测试目标

验证传播 X 光能够真实完成以下闭环：

1. 上传并解析宣传材料和产品/技术资料；
2. 提取可核验宣传主张；
3. 检索候选证据并显示文件、页码或段落；
4. 对引用进行原文逐字校验；
5. 输出五类判断并说明局限；
6. 允许人工确认、修改和驳回；
7. 保存操作留痕；
8. 导出 HTML、Markdown 和 JSON 报告；
9. 无模型配置时明确使用离线规则模式，不伪造模型结果；
10. 拒绝连接非本机模型地址。

## 二、测试分层

### 1. 单元测试

- 中文文本编码识别；
- 文本分块长度与来源位置；
- DOCX 段落和表格解析；
- 中英文数字分词；
- 证据检索；
- 原文逐字引用校验；
- 数值冲突、条件支持、证据不足和绝对化表达规则；
- 本地模型地址限制；
- JSON 提取与模型响应结构校验；
- HTML 报告转义；
- 文件名清理。

### 2. 集成测试

- 三个合成案例从解析到报告生成的完整流水线；
- 每条主张与人工参考答案比对；
- 所有检索证据均通过原文逐字校验；
- SQLite 审核记录与操作事件写入、读取；
- Markdown / HTML / JSON 报告包含证据与 AI 使用披露。

### 3. Streamlit 交互测试

- 首屏和四个页面正常渲染；
- 加载合成案例后生成审核任务；
- 人工确认判断后状态和复核人正确保存；
- 三个报告下载按钮存在。

### 4. 合成验证集评估

当前验证集包含三个明确标注的合成案例，共 14 条宣传主张：

| 案例 | 主要内容 | 主张数 |
| --- | --- | ---: |
| 绿盾一号合成演示案例 | 支持、条件支持、数值冲突、证据不足 | 6 |
| 鲁田保水剂合成演示案例 | 明确支持、条件支持、超出试验范围 | 4 |
| 金穗营养液合成演示案例 | 数值冲突、条件支持、化肥替代与作物范围无依据 | 4 |

评估指标：

- 判断类别与人工参考答案一致率；
- 引用逐字校验通过率；
- 应判为证据不足或冲突但被错误判定为支持的比例；
- 单案例处理耗时；
- 结果文件可复查性。

## 三、复现命令

```powershell
# 完整自动测试
.\.venv\Scripts\python.exe -m pytest

# 生成测试验证记录
.\.venv\Scripts\python.exe scripts\run_verification.py

# 生成合成验证集评估结果
.\.venv\Scripts\python.exe scripts\run_evaluation.py
```

## 四、验收标准

- 自动测试全部通过，且失败数为 0；
- 三个合成案例的 14 条主张全部与人工参考答案一致；
- 所有展示证据通过原文逐字校验；
- Streamlit 页面无运行异常；
- 人工复核后状态、复核人和理由可保存；
- 可导出三种报告格式；
- 报告中明确标注合成数据、分析模式、模型信息和使用边界；
- 未配置本地模型时不出现模型成功或 AI 调用成功的虚假提示。

## 五、结果与局限

实际结果记录在 `docs/evaluation_results.md` 和 `docs/verification.json`。这些结果只针对合成案例，不能外推为真实业务准确率。

尚未开展：

- 真实企业材料测试；
- 真实审核人员可用性测试；
- 真实业务效率对比；
- 扫描件 OCR 测试；
- 本地大模型实际端到端调用测试。

这些项目在后续开展前不得写入已完成或效果提升结论。
