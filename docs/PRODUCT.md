# 产品说明

## 一句话定位

传播 X 光是一款面向山东农业科技和植保产品企业的宣传材料预发布审核工具。它把宣传文案中的可核验主张逐条拆出，在用户上传的产品说明、技术报告和试验资料中寻找原始证据，标出支持、条件缺失、证据不足和资料冲突，再交由人工确认并导出可追溯报告。

## 目标用户与嵌入环节

- **主要用户**：农业科技企业、植保产品企业的市场宣传人员、材料审核人员。
- **使用环节**：公众号推文、产品折页、宣传海报、推介材料发布前。
- **使用频率**：每次材料定稿前，或产品资料更新后。
- **核心决策**：这条宣传能不能保留、需要补什么证据、需要补哪些适用条件、哪些必须升级为人工或专业审查。

## 真实业务问题

农业科技宣传同时涉及产品效果、试验条件、作物范围、登记信息和安全表述。人工审核常遇到三个问题：

1. 宣传句子与资料分散在不同文件中，定位证据耗时；
2. 资料只支持特定试验结果，但文案容易扩展为普遍效果；
3. 普通大模型能给出泛泛点评，却难以稳定显示证据原文和可复核位置。

传播 X 光不追求自动判定真假，而是把“主张—证据—判断—人工结论”整理成可审计流程。

## 核心流程

1. 上传宣传文案、产品说明、技术报告或论文；
2. 解析文本并保留文件名、页码或段落位置；
3. 从宣传材料中提取可核验主张；
4. 对每条主张检索相关原文；
5. 检查数值、范围、绝对化表达和限制语；
6. 对系统展示的引用进行原文逐字校验；
7. 由审核人员确认、修改或驳回；
8. 导出 HTML、Markdown 和 JSON 报告。

## 与普通 AI 点评的区别

| 普通点评 | 传播 X 光 |
| --- | --- |
| 给泛化建议 | 逐条处理宣传主张 |
| 可能不提供来源 | 显示文件、页码或段落及原文 |
| 结论难以追溯 | 引用进行程序化原文校验 |
| 容易把猜测当事实 | 没有证据时只标记证据不足 |
| 人机边界模糊 | 人工可确认、修改、驳回并填写理由 |
| 只输出一段文字 | 导出结构化、可编辑、可留痕报告 |

## 当前实现程度

已经实现：

- 本地 Web 交互；
- 三种文档格式解析；
- 本地证据检索与引用校验；
- 五类判断；
- 人工复核和 SQLite 操作留痕；
- HTML / Markdown / JSON 报告；
- 三个合成案例与自动评估；
- 可选的本机大模型接口，且强制限制回环地址。

尚未完成或尚未验证：

- 真实企业材料和真实审核人员的现场测试；
- 离线 OCR；
- 本地大模型服务在当前机器上的实际端到端调用；
- 大规模真实业务数据评估；
- 法规、登记或知识产权自动审查。

## 价值衡量方式

软件已经能记录每次审核的分析模式、主张数、判断类别、引用校验结果和处理耗时。真实业务价值需要通过企业小范围测试计算，至少包括：

- 单份材料人工审核耗时变化；
- 证据定位正确率；
- 应提示风险被错误放行的比例；
- 审核人员对判断依据的采纳率；
- 人工修改次数和主要修改原因。

当前 3 个合成案例、14 条主张的结果只用于验证流程一致性，不能作为真实业务提升比例对外宣称。

## 适用边界

本工具是宣传材料发布前的证据核对辅助工具，不替代企业审核、专业判断、登记合规检查或法律审查。未检索到证据不等于宣传虚假，系统判断也不是事实认定。
